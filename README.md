## 📥 Como baixar e executar

Para executar o **K-CODE**, é necessário ter o **Python** instalado no computador.

### 1. 🐍 Instale o Python

Baixe e instale a versão mais recente do Python pelo site oficial:

🔗 https://www.python.org/downloads/

> ⚠️ **Importante:** durante a instalação do Python no Windows, marque a opção **"Add Python to PATH"**.

### 2. 📦 Instale o PySide6

Após instalar o Python, abra o **CMD**, PowerShell ou outro terminal e execute:

```pip install PySide6```

Após instalar o Python e o PySide6, baixe e rode o arquivo
```K-Code.py```
